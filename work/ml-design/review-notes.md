# Track 1 ML 设计审视笔记

状态：讨论草稿，尚未取得逐案训练数据，尚未训练或评估模型。

## 核心边界

- 法条画像用于指导检索，由法律成员确认条文、适用版本和分项依据。
- 机器学习辅助识别截至某个时点的材料中可定位的关切证据，以及值得继续核查的候选。
- 羁押事实、庭期和证据缺口分别呈现；行动紧迫性由明确规则表示。

## 待与 Claude 核对

1. 主预测目标是材料中已记录的关切，还是人工进一步核查的建议？避免在一套标签里混合。
2. 信息不充分与模型不确定是两种情况：前者是材料状态，后者是预测状态。
3. A/B/C/D 抽样组不是四个互斥标签；主体身份、案件关系、关切证据应分别记录。
4. 缺少关切叙述不能自动标为负例。非记者案件不是关切任务的默认负例。
5. 同案、关联程序和转载归到同一案件家族；训练测试按案件分组，并保留时间截点。
6. 模型可能只学到人权报告的措辞、来源或后续结论；需要跨来源及早期事实测试。
7. 人为平衡抽样下的模型分数先称排序分数；概率解释需自然候选分布下独立验证。
8. 若标签不足或模型未优于基线，保留规则加证据提取的原型，并如实报告。

## 最小比较

- 关键词或明确规则基线。
- 冻结文本表示加正则化线性分类器。
- 独立案件测试：前 K 条的核查价值、证据支持率、关键漏检、人工核查时间。
- 有可靠历史版本的案例回放，用于单独检验早发现。
